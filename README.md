# Quản lý công việc Phòng KHKT — app điện thoại

Khung app (PWA) mở web app Apps Script "Quản lý Phòng KHKT" toàn màn hình. Không chứa dữ liệu; đăng nhập và dữ liệu vẫn do Apps Script xử lý.

Cài đặt: mở https://vantubkhut-sys.github.io/phong-khkt-app/ trên điện thoại
- Android (Chrome): menu ⋮ → "Cài đặt ứng dụng"
- iPhone (Safari): nút Chia sẻ → "Thêm vào MH chính"
